# Predicting-Obesity-Walkability-ML
Analyzed CDC PLACES and EPA Smart Location data using ML to predict obesity rates from walkability metrics. Gradient Boosting ($R^2\approx 0.78$ $R^2\approx 0.78$, RMSE $\approx 1.99$$\approx 1.99$) outperformed linear models, highlighting non-linear impacts of transit access and employment diversity on public health.
